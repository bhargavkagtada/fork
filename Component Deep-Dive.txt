Component Deep-Dive
1. Azure Functions (Python v2, Blueprint Model)
Location: function_app.py
Role: Entry point for all serverless logic. Registers blueprints for modular function organization.
Features: Durable orchestrators (sync, yield), async activities, logging, environment-based secrets.
Integration: Connects to data layer, agents, and external Azure resources.
2. Data Layer (Cosmos DB)
Location: cosmos_ops.py
Role: Handles all database operations (CRUD, queries) for persistent storage.
Integration: Used by Azure Functions for data access. Provisioned via cosmos-db.bicep.
3. Agents & Tools
Location: agents
Role: Modular utilities for code style enforcement (code_style.py), deep wiki management (deep_wiki.py), and vector search (tools/vector_search.py).
Integration: Invoked by Azure Functions or other components as needed.
4. Infrastructure-as-Code (IaC)
Location: infra
Role: Bicep templates for provisioning all Azure resources (Function App, Cosmos DB, Cognitive Services, RBAC, Monitoring).
Integration: Deployed via Azure Developer CLI (azd). Ensures reproducible cloud environments.
5. Configuration & Environment
Location: local.settings.example.json, scripts/generate-settings.*
Role: Manages environment variables, secrets, and settings for local and cloud deployments.
Integration: Used by Azure Functions and agents for secure configuration.
6. Testing
Location: tests
Role: Automated tests using pytest and pytest-asyncio. Mocks Azure SDK calls for coverage.
Integration: Validates all business logic and integrations.
7. Documentation & Metadata
Location: Root files (README.md, deep-wiki.md, etc.)
Role: Provides usage, contribution, and change history information.
